# Contributing

Thank you for helping improve the register. Never include real student, staff or financial data in an issue, pull request, screenshot or test.

## Report a bug or suggest an idea

1. Open the **Issues** tab and choose **New issue**.
2. Use the "Report a problem" form and describe what happened.

## Change the site from the GitHub website

1. Open the file, click the pencil icon, make the change.
2. Choose **Create a new branch for this commit and start a pull request**.
3. The **Checks** workflow builds the site and runs the tests. Merge only when it shows a green tick.

## Working on a computer (developers)

The site is plain HTML, CSS and JavaScript modules assembled by a dependency-free Node script.

```bash
node scripts/build.mjs        # writes dist/
node scripts/check.mjs        # link, CSP and privacy checks on dist/
pip install -r tests/requirements.txt && python -m playwright install chromium
tests/run.sh                  # end-to-end tests using test doubles for Firebase
```

Tests use `tests/fixtures/sample-data.json`, a fictional dataset generated by `tests/fixtures/make_sample_data.py`. Real school data must never be added to the repository.

## Conventions

- Colours, type and spacing live in `src/assets/css/tokens.css`; do not hard-code values elsewhere.
- No inline `style` attributes or inline scripts (the Content Security Policy blocks them).
- Escape every value written into HTML with `esc()` from `src/assets/js/lib/util.js`.
